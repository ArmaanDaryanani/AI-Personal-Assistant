# AI Personal Assistant
**AI Personal Assistant for the visually impaired for use on the Portenta H7.**

This script allows for constant data sharing between a personal device and the receiver of choice.

Note: Full code is not available for the public.

## Introduction
The AI Personal Assistant is designed to assist the visually impaired by leveraging the capabilities of the Portenta H7 microcontroller. 
It facilitates continuous data sharing between a personal device and a receiver, enhancing accessibility and user experience.

## Features
- Real-time Data Sharing: Enables continuous communication between devices.
- Optimized for Portenta H7: Utilizes the microcontroller's dual-core architecture for efficient processing.
- Accessibility Focused: Enhances user experience for visually impaired individuals.

## Hardware Requirements
- Arduino Portenta H7
- MEMs Microphone Sensor
- Bluetooth Module
- Receiver Device (e.g., smartphone, tablet)

## Usage
The AI Personal Assistant operates by continuously sharing data between the Portenta H7 and a receiver device.
This allows for real-time assistance and feedback tailored to the needs of the visually impaired.
